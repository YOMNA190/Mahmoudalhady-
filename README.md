# Familia Website

A responsive family-oriented website with a warm visual direction and a component-based frontend structure.

## Overview

A family-oriented React web experience built with TypeScript, Vite, and Tailwind CSS.

## Highlights

- Responsive family-focused experience
- Reusable React component structure
- Modern styling and visual system
- Vite-based development workflow

## Tech stack

React, TypeScript, Vite, Tailwind CSS, ESLint

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown by the development server. For a production build:

```bash
npm run build
npm run preview
```

## Available scripts

| Script | Command |
|---|---|
| `dev` | `vite` |
| `build` | `tsc -b && vite build` |
| `lint` | `eslint .` |
| `preview` | `vite preview` |

## Project structure

The application code lives in `src/`, static assets are served from `public/`, and the project configuration is kept at the repository root.

## Environment variables

Do not commit credentials or production secrets. Copy the example environment file when one is provided and keep local secrets in `.env.local`.
